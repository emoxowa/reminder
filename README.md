# Напоминалка для macOS

Приложение на Python + tkinter, напоминания хранятся в SQLite3 (`~/.reminder_app/reminders.db`).

## Запуск

```bash
/usr/local/bin/python3 main.py
```

Нужен Python со сборкой tkinter (например, установщик с python.org). Сторонние зависимости не нужны.

## Структура

- `db.py` — работа с SQLite: создание таблиц и миграция старой базы при старте, CRUD, выборки для планировщика.
- `recurrence.py` — правила повтора и расчёт следующего срабатывания.
- `notifier.py` — системные уведомления macOS (`osascript`), всплывающее окно поверх всех окон, планировщик проверок.
- `gui.py` — главное окно: список с фильтром по статусу, добавление, удаление, смена статуса.
- `main.py` — точка входа.

## Как работают статусы

- Новое напоминание получает статус «Ожидает».
- Когда наступает время, приходит системное уведомление и открывается окно поверх остальных с кнопками «Готово», «Отложить на 10 мин» и «Закрыть».
- Если через 5 минут после срабатывания напоминание всё ещё «Ожидает», оно переходит в «Просрочено».
- Напоминания, время которых прошло, пока приложение было закрыто, срабатывают при следующем запуске.

## Повторяющиеся напоминания

При создании выберите повтор: «Однократно», «Каждый час», «Ежедневно», «По будням», «Еженедельно», «Ежемесячно» или «Ежегодно».

- «Готово» у повторяющегося напоминания закрывает только текущий раз: оно переносится на следующую дату и остаётся «Ожидает».
- Пропущенный раз (нет реакции 5 минут) тоже переносится на следующую дату, а не становится «Просрочено».
- «Отложить» сдвигает только текущее срабатывание (в списке помечено ⏸), расписание серии не меняется.
- «Отменить» останавливает всю серию.
- Даты считаются от первой даты серии: ежемесячное на 31-е сработает 28 февраля, а в марте снова 31-го.
- Если первая дата серии уже прошла, напоминание сработает в ближайший будущий раз.
- В списке можно фильтровать по типу: одноразовые или повторяющиеся.

Проверка идёт каждые 5 секунд через `after()` в цикле Tk, поэтому она работает, даже когда окно свёрнуто. Если закрыть приложение, напоминания приходить не будут.
